# Vanta Client — Minecraft 26.2

A purple-black, highly customizable Fabric client focused on legit PvP HUD, survival/QoL, visual customization and performance controls.

## Controls
- **Right Shift** — Vanta module menu
- **Right Ctrl** — HUD editor
- **C** — Zoom

## Integrated feature set
Vanta carries the clean-room feature equivalents from the previous Orbit project: Auto Sprint, Armor HUD, Totem Counter, numeric Ping, Food/Saturation HUD, configurable Crosshair, module search, Waypoint, Shulker Preview, Chat Heads, Skin Layers controls, Distant Chunks controls, Client Optimizer, Tier Tag, Fullbright, Low Fire, Low Shield, particles, custom sky/time/weather controls, FPS/HUD info, counters, chat tools and more.

**Quick Swap is intentionally removed.**

## 26.2 port
Minecraft 26.2 uses the unobfuscated Mojang-named codebase, Fabric Loom `net.fabricmc.fabric-loom`, Java 25, and a newer rendering/input stack. This source has the 26.2 build setup and Vanta branding in place; renderer-heavy code may still need API adjustments surfaced by the first GitHub Actions compile.
